name: extract-payment-xlsx
description: 从收款凭证截图（银行电子回执、承兑汇票、背书制单等）中提取付款方和金额，汇总生成 xlsx 表格
type: prompt
whenToUse: 当用户要求从财务收款截图、银行回单、承兑汇票图片中提取付款方/金额并整理成 Excel/xlsx 表格时
arguments:
  - dir
---

从指定目录（未指定则为当前工作目录）$dir 中的收款截图提取付款方与金额，生成 xlsx 汇总表。

步骤：

1. 列出目录中的图片文件（png/jpg/jpeg 等），用 ReadMediaFile 逐张读取（可并行）。
2. 每张图可能包含多张回执（上下拼接），逐一提取，常见凭证类型与付款方字段：
   - 银行网上电子回执 / 银行回单：付款方 = "付款人 全称"；金额 = "小写金额" 或 "金额"。
   - 电子银行承兑汇票（出票票面）：付款方 = "收票人 全称"（即把票据背书转让给本公司的直接上家），不要取出票人；金额 = "票据金额"（大写金额可用于核对小写数字）。
   - 承兑汇票背书应答制单：付款方 = "背书人 全称"；金额 = "票据（包）金额（元）"。
   - 同时记录凭证类型和日期（回执取"日期"，汇票取"出票日期"），便于财务核对。
3. 将结果整理为 JSON，字段为 payer（付款方）、amount（金额，数字）、type（类型）、date（日期）、source（来源文件名）。
4. 调用本技能自带脚本生成 xlsx（零依赖，仅需 Node）：

   ```bash
   node "${KIMI_SKILL_DIR}/scripts/build_payment_xlsx.js" data.json 收款记录.xlsx
   ```

   脚本自动添加表头（序号/付款方/金额(元)/类型/日期/来源文件）和末行"合计"。
5. 若环境中没有 Node，可改用 Python+openpyxl（需在隔离环境安装依赖），或告知用户。
6. 生成后向用户汇报：记录条数、合计金额、输出文件路径；如某张图识别不确定（金额大写与小写不一致、文字模糊），明确指出请用户人工核对。
